# auto-stock-trading

AI 를 활용한 주식 트레이딩 앱입니다.

재귀 개선(recursive improvement)을 통한 1일 1회 알고리즘 개선 아이디어에서 시작했습니다. 매일 트레이딩 결과를 스스로 평가하고, 그 결과를 바탕으로 알고리즘을 조금씩 개선해 나가는 것을 목표로 합니다.

## 프로젝트 소개

- **컨셉**: 하루 1회 주기로 트레이딩 알고리즘의 성과를 평가하고, 이를 반영하여 다음 알고리즘을 개선하는 재귀적 자기 개선 구조
- **목표**: 사람이 매번 전략을 수정하지 않아도, 시스템이 스스로 성과를 분석하고 전략을 다듬어 나가는 자동화된 트레이딩 앱

## 현재 상태

이 저장소는 아직 초기 단계로, 프로젝트 소개를 담은 README만 존재하며 실제 소스 코드, 의존성 관리, 실행/테스트 방법은 아직 정해지지 않았습니다. 언어/스택, 프로젝트 구조 등 구체적인 내용은 앞으로 확정되는 대로 이 문서에 추가할 예정입니다.
